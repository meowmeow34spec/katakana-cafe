# ☕ 가타카나 카페

**가타카나 외우기 귀찮은 사람들을 위한 3D 카페 게임**

カタカナ를 보고 "이거 뭐라 읽냐…" 하다가 포기한 적 있다면, 이 게임을 해 봐.
**외우는 게 아니라, 커피를 팔다 보면 저절로 외워져.**

👉 **[지금 바로 플레이](https://meowmeow34spec.github.io/katakana-cafe/)**

## 이렇게 해
- 손님이 와서 「コーヒー 주세요」라고 주문해.
- 그걸 읽고 맞는 블록을 잡아서 서빙하면 돼.
- 틀리면 손님이 화내 ㅋㅋ

## 들어 있는 것
- 기본 가타카나 46자 전부
- 커피, 케이크, 아이스크림처럼 이미 아는 외래어로 배워서 머리에 오래 남아.
- 그림이 글자로 바뀌는 연출이라 글자 모양이 기억에 남아.
- 틀린 글자는 알아서 다시 물어봐.
- 보스전도 있어. (ア랑 マ 헷갈리는 사람은 각성 주의)
- 설치, 회원가입, 광고 없이 완전 무료

## 참고
- PC 크롬을 추천해. 폰에서는 조금 무거울 수 있어.
- 진행 기록은 내 브라우저에만 저장돼.
- 보스를 하트 3개로 깨면 인증 박아라 ☆
